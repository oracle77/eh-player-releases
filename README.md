# EH Player 배포 저장소

개인용 안드로이드 앱 EH Player 의 APK 만 올라오는 저장소입니다. 소스 코드는 포함하지 않습니다.

- 앱 안의 업데이트 기능이 이 저장소의 최신 릴리스를 확인하고, sha256 이 일치할 때만 설치를 안내합니다.
- 첫 실행 시 만 19세 이상 자가 확인(본인 신고, 실명 인증 아님)에 동의해야 사용할 수 있습니다.
- 비공식 앱이며 YouTube·Google 과 무관합니다. 영상의 시청·저작권 책임은 사용자에게 있습니다.
- 로그인, 쿠키, 연령 확인 우회 기능이 없습니다. 연령 확인이 필요한 영상, 유료·대여·멤버십 전용 영상, DRM 보호 영상은 재생되지 않을 수 있습니다.
- 개인 사용 전용입니다. APK 와 영상의 재배포를 금지합니다.
